# Правила для автоматизированных изменений

- Прочитайте `README.md`, `CONTRIBUTING.md`, `ROADMAP.md` и относящиеся к задаче файлы в `docs/` перед изменением кода.
- В репозитории реализованы импорт JSON, копия v2 и локальные SQLite-реестры. Не описывайте функции автономного HTML как готовые функции Vue-приложения.
- Данные ПУ-66 конфиденциальны и хранятся только в `private-data/` на компьютере составителя. Никогда не добавляйте реальные карточки, локальную SQLite или резервные копии в GitHub.
- Не импортируйте содержимое локального HTML-прототипа, карточки ПУ-66, исходные PDF стандартов или их изображения в публичный репозиторий без подтверждённых прав и проверки допустимости публикации.
- Для правил размещения знаков указывайте редакцию и пункт нормативного источника. Выбор Б.33 при ровно 30 м — решение проекта: подписи рисунков ОДМ и размерные обозначения расходятся, требуется предметная сверка. Не превращайте примеры в универсальные нормы без проверки.
- Сохраняйте совместимость старых JSON-проектов через версионируемый импорт, когда формат появится в приложении.
- Используйте `npm run check` перед PR. Добавляйте предметные тесты при изменении расчётов, импорта, экспорта и шаблонов.
- Обновляйте документацию и changelog при изменении поведения пользователя. Не публикуйте и не разворачивайте приложение автоматически.
