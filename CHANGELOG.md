# История изменений

Формат основан на Keep a Changelog. До появления рабочего редактора версии `0.x` обозначают этапы разработки, а не пригодность схем к использованию.

## [Unreleased]

### Добавлено

- Просмотр перенесённых параметров, реквизитов и объектов с координатами SVG для сверки импорта.
- Обезличенный пример Б.34 с ручными правками и проверками сохранности данных при переносе.
- Проект процедуры подготовки данных ПУ-66 для будущего каталога; фактическая загрузка ещё не реализована.
- Типизированная модель `schemaVersion: 2` и проверяемый импорт JSON `v: 1`.
- Интерфейс загрузки проекта, отчёт о переносе и скачивание копии v2 и исходного JSON.
- Тесты на сохранение ручных объектов, ошибки входных данных и повторное открытие v2.

## [0.1.0] — 2026-09-26

### Добавлено

- Исходный каркас Vue 3 и TypeScript на Vite.
- Проверки форматирования, линтеров, типов и сборки в CI.
- Правила разработки и ревью, нормативный реестр, план миграции и дорожная карта.

### Примечание

- Функции редактирования схем из автономного прототипа пока не перенесены.
