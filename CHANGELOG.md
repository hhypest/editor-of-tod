# История изменений

Формат основан на Keep a Changelog. До появления рабочего редактора версии `0.x` обозначают этапы разработки, а не пригодность схем к использованию.

## [Unreleased]

### Добавлено

- Пересчитываемая проверка заполнения черновика: пустые поля, ссылки стоек на незаданные расстояния, пункты ручной сверки ПУ-66, варианта, знаков и пограничного фронта 30 м. Проверка не меняет JSON и не устанавливает нормативный статус.
- Явная привязка импортированной карточки ПУ-66 после сравнения значений с проектом; в JSON v4 записываются только отобранные поля, номер и время обновления локальной редакции. Новую редакцию карточки нужно выбирать заново.
- Чтение v3 и сохранённых редакций SQLite с преобразованием в v4 без переписывания старых снимков.
- Создание проекта без исходного JSON с ручным вводом данных переезда, измеренных размеров и скоростей; выбранный вариант Б.33/Б.34 записывается без фиктивных размеров другого варианта.
- Формат JSON v3 с явным источником проекта; v1/v2 и старые редакции локальной SQLite читаются с преобразованием, при этом сохранённые старые снимки остаются прежними.
- Локальное сохранение нескольких JSON-черновиков в SQLite с историей редакций, открытием и восстановлением. Конфликт устаревшей редакции отклоняется; прежние редакции можно скачать отдельно. База обновляется до версии 4 без переноса рабочих данных в Git.
- Координатная рабочая область импортированного проекта с привязками Б.33/Б.34, локальными PNG знаков, выбором объекта, масштабом и перемещением мышью или стрелками. Перемещение сохраняет привязку и попадает в историю одним действием.
- Панель объектов для правки стойки/элемента, добавления ручной стойки и надписи, удаления объекта, просмотра исходных PNG знаков и отмены/повтора до 30 применённых действий.
- Редактирование параметров обеих зон работ, расстояний, скоростей и реквизитов импортированного проекта; проверка чисел, отмена неприменённого ввода и сохранение обновлённого JSON v2.
- Локальный пакетный импорт XLSX-карточек ПУ-66 с сохранением исходников, извлечённых полей и ограниченной выборкой для схемы.
- Импорт двух вариантов PNG для каждого дорожного знака и просмотр каталога в приложении.
- Локальные SQLite-реестры ПУ-66 и нормативных пунктов: ручные записи, история редакций и резервная копия вне Git.
- Предварительный выбор Б.33/Б.34 по длине фронта работ с явным предупреждением для 30 м.
- Просмотр перенесённых параметров, реквизитов и объектов с координатами SVG для сверки импорта.
- Обезличенный пример Б.34 с ручными правками и проверками сохранности данных при переносе.
- Проект процедуры актуализации данных ПУ-66 линейным подразделением.
- Типизированная модель `schemaVersion: 2` и проверяемый импорт JSON `v: 1`.
- Интерфейс загрузки проекта, отчёт о переносе и скачивание копии v2 и исходного JSON.
- Тесты на сохранение ручных объектов, ошибки входных данных и повторное открытие v2.

### Удалено

- Автоматическая трассировка дорожных знаков в SVG, её переключатель в каталоге и производные SVG в локальной SQLite. При обновлении базы до версии 3 обе исходные версии PNG сохраняются.

## [0.1.0] — 2026-09-26

### Добавлено

- Исходный каркас Vue 3 и TypeScript на Vite.
- Проверки форматирования, линтеров, типов и сборки в CI.
- Правила разработки и ревью, нормативный реестр, план миграции и дорожная карта.

### Примечание

- Функции редактирования схем из автономного прототипа пока не перенесены.
