| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

Регрессионный тест с Vue `reactive`, сценарий Chromium в CI.                                                                                                                        |
| P0-2, станционные карточки     | Если участок пуст, используется `ст.<станция>:<км>:<пк>`; при отсутствии обоих полей импорт отклоняется. Добавлена пятая вымышленная XLSX и тест.                                                                                                                                  |
| P0-3, новые поля v1            | Формат v5 сохраняет `fz`, `n100/n50`, `front`, `reg`, `loc`, `size`, `vIn`, `locLast`, `zPu`. Неизвестные ключи получают предупреждение; есть обезличенный тестовый файл.                                                                                                          |
| P0-4, печать                   | Не относящиеся к листу блоки убираются из потока через `display: none`. Координаты являются эскизом, точный состав знаков и нормативная применимость остаются на предметной проверке.                                                               |

| P1-3, поля ПУ-66               | В белый список листа новые поля не добавлены: суточное число автомобилей нельзя прямо подставить вместо авт./ч, а состав передаваемых сведений ограничен владельцем данных. Решение записано в `pu66-data.md`.                                                                     |
| P1-4, лист                     | Коды знаков подписываются, пересечение стоек блокирует печать, направления проверяются на обрезание. Режим выпускного листа и визуальная предметная сверка пока отсутствуют.                                                                                                       |
| P1-5, закрепление PNG          | По явному действию схема v5 сохраняет идентификатор каталога и редакцию каждого использованного кода. Лист и рабочая область читают исторический PNG по `?rev=N`, ответ кэшируется как неизменяемый. Для старых файлов без закрепления остаётся текущий каталог.                   |
| P1-6, объём базы               | SQLite v7 хранит один исходный JSON по SHA-256 для новых редакций; старые снимки остаются без переписи. Просмотр очистки копий доступен через CLI (20 последних, не старше 90 дней, минимум одна), удаление только с `--apply`. Организационную политику хранения нужно утвердить. |
| P1-7, миграции                 | Ошибка любой миграции откатывает открытую транзакцию и закрывает SQLite; тест проверяет повторное открытие после сбоя. Выделение всех миграций в отдельный каталог остаётся задачей обслуживания.                                                                                  |
| P1-8, сервис                   | SQL-запрос последней редакции знака подготовлен один раз; одинаковые PNG не дублируются при смене метки источника; HTML вместо JSON даёт понятную ошибку.                                                                                                                          |
| P1-9, размер App.vue           | Состояние проекта, история, импорт/экспорт и локальные операции вынесены в `useProjectSession`. В `App.vue` остались навигация, реестры и представление; сценарии Chromium проверяют переходы.                                                                                     |
| P1-10, браузерные сценарии     | Playwright в CI проверяет создание и применение формы, новый v1, синтетический импорт XLSX/ZIP, число страниц PDF и ошибки `pageerror`. Локально: `npx playwright install chromium && npm run test:e2e`.                                                                           |

Перед выпуском нужны предметная проверка Б.33/Б.34 в нескольких дорожных условиях, утверждённая политика хранения и выпускной лист. Наличие зелёного CI не подтверждает нормативную пригодность схемы.
