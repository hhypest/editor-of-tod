### Проверки и приёмка

- CR1: `npm run check`, 273 теста; CR2: `npm run check`, 277 тестов.
- CR3 и вся цепочка: `npm run check`, 47 файлов, 279 тестов; линтеры, типы, проверка прямого запуска Node и сборка проходят. `npx playwright test --list` находит 21 сценарий.
- Собран Linux SEA (Node.js 24.19.0, с проверкой лицензий); smoke двух папок подтвердил разные базы/порты, встроенный интерфейс и повторный запуск той же базы, в том числе после освобождения основного порта. Это не заменяет приёмку Windows.
- Playwright-сценарии добавлены, но локально не запускались: загрузка Chromium завершилась ошибкой (неполный архив). Это ограничение не считается успешной локальной браузерной проверкой. CI PR № 64 прошёл, включая Chromium и Windows. Первый CI CR2/CR3 обнаружил ошибку регистра в ожидании recovery, жёстко заданную редакцию повторно импортируемой тестовой карточки и переиспользование закрытого HTTP-соединения в тесте смены базы. Ожидания исправлены, тест PNG читает тело и закрывает соединение; повторный CI отслеживается в проверках PR.
- Печать/PNG и две копии новой сборки на Windows требуют приёмки на рабочем месте. Нормативная пригодность не подтверждается автоматическими тестами.
