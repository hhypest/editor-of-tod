После перевода рабочего запуска в #225 удалены `server/store.ts`, `server/compatibility-server.ts` и прежние экспорты из index. Диагностическая сводка импортируется только у своего владельца, сообщение о миграции — из database/migration-notice. ## Контракты обращаются к владельцам

Сохранённые API, SQLite, миграционные и конкурентные сценарии больше не создают RegistryStore. В тестах вызываются реальные projects/recovery/legacy, сервисы импорта/lifecycle, documents/documentService/documentText, parameterConfirmations, signCatalog и команда удаления. Например, сохранение проекта обращается к projects.save, запись recovery передаёт одну команду recovery.save({ input, ownerId, sourceSha256 }); атомарность остаётся внутри прежнего репозитория.

`server/__tests__/test-application.ts` создаёт настоящие сервисы через createServerServices и связывает их с той же composeServerRuntime, которую использует production. Помощник возвращает владельцев и runtime на одном соединении. Он не копирует прежние domain forwarding methods и не становится новым RegistryStore под другим именем. Тесты HTTP используют createHttpServer(runtime.http), загрузок — соответствующие узкие команды, диагностики — её количественные запросы. Подмены сбоев адресуются тому же владельцу или конкретному command port, который выполняет операцию.

createServerRuntime по-прежнему открывает и инициализирует одну базу; composeServerRuntime только связывает уже созданные сервисы и передаёт владение соединением runtime. SQL, row mappers, миграции, seed, транзакции, порядок clock reads и прикладные алгоритмы не меняются. Проверки receiver часов используют явный bind к контексту вызывающего: тестируют доставку callback и число вызовов, без зависимости от экземпляра удалённого класса.

## Сохранение проверок

Ни один тестовый случай не удалён и не пропущен. При переносе проверены все SQL fixture statements в 45 изменённых тестовых файлах. Ожидаемые payload/status/ошибки, значения, версии, rollback, конкуренция, lease/owner, source SHA, история, лимиты и графика сохраняются. Удалены десять проверок идентичности старых реэкспортов: соответствующих экспортов больше нет; проверки отказов используют исходные конструкторы у владельцев. Четыре проверки receiver класса заменены проверками явного clock context, шесть сохранённых проверок receiver также используют этот контекст. Новых зависимостей нет.

Полный локальный npm run check: **129 файлов / 979 тестов**, архитектура/формат/lint/типы, Node API/CLI/desktop и production build. Полный локальный Chromium E2E: **56/56 без повторов**. Результаты CI Linux/Windows и Windows exe на итоговом дереве, commit/tree фиксируются в PR и #135. Ранее выполненные проверки #225 не считаются проверкой удаления фасада.
