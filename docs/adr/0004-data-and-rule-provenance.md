# ADR-0004. Ограниченные данные и происхождение правил

Статус: **Ограниченный снимок ПУ-66 принят и реализован; сохранение нормативного основания запланировано в П3**. Зафиксировано: 02.10.2026.

## Контекст

Обновление реестра не должно менять историческую схему. Полная карточка и исходная книга конфиденциальны. Подтверждение нормативного параметра зависит от редакции документа и не должно терять происхождение.

## Решение

Проект закрепляет только разрешённый ограниченный снимок ПУ-66. Полные книги, технические таблицы, PDF и изображения остаются в локальной базе. Нормативные параметры уже имеют источники и журнал подтверждений; числа в расчётах берутся из `NormativeRules`. П3 должен определить и сохранять ограниченное основание выбора режима и использованные редакции параметров.

## Альтернативы

Ссылка только на текущую карточку меняла бы исторический результат при обновлении реестра. Копирование всей карточки и исходных документов расширяло бы экспорт конфиденциальных данных. Использование только текущих нормативных значений без исторического основания затрудняет объяснение старого проекта.

## Последствия

Открытие проекта не обновляет снимок молча. Экспорт содержит только установленный контрактом состав данных. При реализации П3 нужно различать историческое основание и проверку по текущим правилам, определить состав сохраняемых полей и миграцию. Этот ADR не объявляет нормативный профиль частью нынешнего формата v7.

## Пересмотр

Менять состав снимка или основания только после согласования с владельцем данных и обновления контракта, миграций и проверок экспорта. Новая задача согласования не даёт автоматического основания передавать полный реестр.
