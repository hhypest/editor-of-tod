# Архитектурные решения

[Архитектура](../architecture.md) · [Дорожная карта](../../ROADMAP.md)

ADR фиксируют причины решений, альтернативы и условия пересмотра. Статус «Принято» ниже документирует уже существующее устройство программы или ранее записанное решение составителя; он не объявляет будущую функцию реализованной.

| ADR                                      | Статус                                    | Решение                                                                   |
| ---------------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------- |
| [0001](0001-local-application.md)        | Принято                                   | Локальное приложение, SQLite и Node.js SEA; Tauri отложен                 |
| [0002](0002-project-and-sheet.md)        | Принято                                   | Scheme — сохраняемый источник данных, представление листа производное     |
| [0003](0003-schematic-distances.md)      | Принято; Р1 реализован в ADR-0008         | Схематический лист без равномерного масштаба                              |
| [0004](0004-data-and-rule-provenance.md) | Принято; часть П3 реализована в ADR-0007  | Ограниченный снимок данных и происхождение нормативных параметров         |
| [0005](0005-pu66-lifecycle.md)           | Реализовано; предметная приёмка предстоит | Обратимое исключение, журнал и ручной выбор преемника                     |
| [0006](0006-modular-application.md)      | Принято; CR5 реализован, А3–А5 постепенно | Модульный монолит, независимые сценарии и владение копиями восстановления |
| [0007](0007-decision-evidence.md)        | Реализовано; предметная приёмка предстоит | JSON v9: условия скорости и исторические основания скорости/регулирования |
| [0008](0008-post-distance.md)            | Реализовано; предметная приёмка предстоит | JSON v10: расстояние стойки до начала работ, шкала листа без масштаба     |

При новом решении добавляйте следующий номер, дату, контекст, альтернативы, последствия и условия пересмотра. Изменение принятого решения объясняется новым ADR со ссылкой на предыдущий; история причин сохраняется.
