# ADR-0001. Локальное приложение, SQLite и Node.js SEA

Статус: **Принято; документирует существующее устройство**. Зафиксировано: 02.10.2026. Решение об отсрочке Tauri записано 30.09.2026.

## Контекст

Один составитель готовит схемы на своём компьютере, использует конфиденциальные карточки, локальные изображения и нормативные PDF. Нужны импорт Excel/PDF, версии проектов и запуск на рабочем месте без установки Node.js.

## Решение

Сохраняем Vue/TypeScript, локальный Node.js API на `127.0.0.1`, SQLite и переносную Windows-сборку Node.js SEA. База создаётся при запуске и хранится отдельно от программы. Сетевой сервис организаций и совместная работа в этот механизм не входят.

## Альтернативы

- Внешняя СУБД и сетевой сервер требуют эксплуатации и доступа к данным, которых текущий сценарий не требует.
- Немедленный переход на Tauri потребовал бы переноса серверных функций либо поставки Node.js рядом; дополнительно нужно проверить WebView2 и корпоративные политики. Сейчас этого выигрыша недостаточно.

## Последствия

SQLite не добавляется в репозиторий. Сохранение, резервное копирование, обновление и восстановление проверяются отдельно. Повторный запуск сравнивает fingerprint канонического файла базы; другая база запускается на другом порту. Переносимость каталога сохраняется, подпись кода и окно без консоли остаются отдельными задачами.

## Пересмотр

Вернуться к решению при потребности в совместной работе, установщике и автообновлении для многих рабочих мест либо запрете локального Node.js API. Причины выбора и миграцию описать до изменения технологии.
