# ADR-0002. Проект и производное представление листа

Статус: **Принято; документирует существующий поток данных**. Зафиксировано: 02.10.2026.

## Контекст

Один проект должен одинаково отображаться в предпросмотре, печати и PNG, сохранять совместимость старых JSON и поддерживать отмену правок. Независимые сохраняемые копии геометрии легко расходятся.

## Решение

`Scheme` остаётся сохраняемым источником данных. `projectDraftSheet()` строит ограниченную проекцию `DraftSheet`, `drawSheet()` — `SheetDrawing` и `SheetNode[]`, `SheetNodes.vue` — SVG. PNG создаётся из этого SVG. UI-состояние выделения и масштаба просмотра хранится отдельно; история отмены работает со снимками Scheme.

## Альтернативы

Прямое изменение SVG или отдельная сохраняемая LayoutModel потребовали бы синхронизации двух моделей и миграций без установленной потребности. Новую модель с таким названием не вводим только ради структуры каталогов.

## Последствия

Рендеринг получает проекцию, а не полный ПУ-66 или исходный JSON. Экранная рабочая область пока отдельная: это известный долг Р2. Её будущее объединение с листом расширяет существующие примитивы связями с объектами и геометрией выбора; жест пользователя должен менять Scheme, после чего представление пересчитывается. Интерактивный слой не включается в печать.

## Пересмотр

Отдельное сохраняемое представление обсуждать только при появлении самостоятельной редактируемой компоновки листа, которую нельзя однозначно вывести из проекта. До этого нужны примеры и правила владения данными.
