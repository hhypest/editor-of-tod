## Архитектура и история проекта

- [Архитектура](architecture.md) описывает существующие модули и отдельно отмечает будущие изменения.
- [Контракты рефакторинга](refactoring-contracts.md) фиксируют baseline, совместимость review и рисунка, ограничения контроля зависимостей.
- [ADR](adr/README.md) фиксируют причины решений и условия их пересмотра.
- [Перенос прототипа](migration.md) и [сравнение с прототипом](prototype-comparison.md) объясняют происхождение требований. Они не заменяют дорожную карту.
- [Разбор прежнего code review](review-follow-up.md) — исторический журнал замечаний; текущая очередь находится в ROADMAP.
- [Правила разработки](../CONTRIBUTING.md) определяют порядок изменений и проверок.

## Как поддерживать документы

README остаётся короткой точкой входа. Пользовательские инструкции обновляются в руководстве и встроенной справке; команды и устройство — в профильных документах. Новое поведение фиксируется в CHANGELOG, выполнение задач — в ROADMAP, причины архитектурного выбора — в ADR. Возможности прототипа и предложения не отмечаются как реализованные функции.
