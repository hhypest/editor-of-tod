- **Условие:** в каждой копии сохраняются уведомление об авторском праве и текст лицензии. Для исполняемого файла это файлы `LICENSE.txt`, `LICENSE.ru.txt` и `THIRD_PARTY_LICENSES.txt`, которые сборка кладёт рядом с `editor-of-tod.exe`; передавайте их вместе с программой.

Лицензия MIT действует для всего кода, документации, тестов и вымышленных примеров в этом репозитории. Вклад в репозиторий принимается на тех же условиях ([CONTRIBUTING.md](../CONTRIBUTING.md)).

## Сторонние компоненты

В программу входят только свободные компоненты с разрешительными лицензиями: MIT, ISC, BSD-2-Clause, BSD-3-Clause, Apache-2.0, Unlicense, Zlib и совместимые. Они разрешают бесплатное использование, изменение и распространение, в том числе в составе программы под MIT, и требуют сохранять уведомления об авторстве и тексты лицензий (Apache-2.0 — ещё и файлы NOTICE).

| Часть программы        | Основные компоненты                                                                                        | Лицензии                                   |
| ---------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| Интерфейс (в браузере) | Vue 3 (`@vue/*`), zod                                                                                      | MIT                                        |
| Локальный сервер       | exceljs и его зависимости (чтение книг XLSX), pdfjs-dist (разбор PDF), pngjs, fflate, zod                  | MIT, ISC, BSD, Apache-2.0, Unlicense, Zlib |
| Среда выполнения в exe | Node.js той же версии, что собирала программу, со встроенными библиотеками (V8, OpenSSL, ICU, libuv и др.) | MIT и лицензии встроенных библиотек        |

Точный состав с версиями формируется при каждой сборке:

- плагин `thirdPartyLicenses` в `vite.config.ts` берёт пакеты, фактически вошедшие в сборку интерфейса, и пакеты сервера из сборки esbuild той же конфигурации, что у исполняемого файла (`scripts/third-party-licenses.ts`);
- в сборку попадают `legal/THIRD_PARTY_LICENSES.txt` (полные тексты лицензий и NOTICE каждого пакета и лицензия Node.js) и `legal/third-party.json` (список для справки);
- `npm run build:exe` кладёт `THIRD_PARTY_LICENSES.txt` рядом с исполняемым файлом и останавливается, если в нём нет лицензии Node.js; рабочий процесс «Windows exe» сохраняет эти файлы в артефакте вместе с программой;
- в программе список и тексты открываются в справке: «Справочник» → «О программе и лицензии».

Инструменты разработки (Vite, TypeScript, ESLint, Vitest, Playwright и др.) в программу не входят и в перечень не попадают.

### Проверка лицензий при сборке

Сборка останавливается, если у пакета, вошедшего в программу, лицензия не из разрешённого списка (`ALLOWED_LICENSES` в `scripts/third-party-licenses.ts`) или нет текста лицензии. Для пакетов с двойной лицензией выбирается разрешительная: `jszip` — «MIT OR GPL-3.0-or-later», используется MIT. Если у пакета в package.json лицензия не указана, условие записывается явно в `LICENSE_OVERRIDES` с источником:

- `buffers` 0.1.1 (зависимость чтения XLSX) — в package.json лицензия не указана, README исходного репозитория substack/node-buffers указывает MIT/X11.

Пакеты без файла лицензии, но с указанной лицензией MIT или ISC (например, `saxes`, `chainsaw`) получают стандартный текст лицензии с автором из package.json.

## Добавление зависимости

1. Проверьте лицензию пакета и его зависимостей: допустимы только лицензии из разрешённого списка. Копилефт (GPL, LGPL, AGPL, MPL и т. п.) и лицензии с ограничениями на коммерческое или служебное использование не добавляются.
2. Выполните `npm run build-only`: при неподходящей лицензии сборка остановится с названием пакета.
3. Если пакет без указанной лицензии необходим, найдите условие в его исходном репозитории и добавьте запись в `LICENSE_OVERRIDES` со ссылкой на источник.
4. Упомяните новую зависимость и её лицензию в описании PR.
