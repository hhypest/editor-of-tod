# Формат проекта версии 2

Новый файл — JSON-объект с `schemaVersion: 2`. Файлы обрабатываются локально в браузере. Импорт и экспорт реализованы в `src/domain/`; их поведение проверяется обезличенными тестами. Текущая версия формата создана для переноса состояния автономного редактора, а не для выпуска согласованной схемы.

| Поле                               | Содержание                                                                                                                                |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `schemaVersion`, `id`, `createdAt` | Версия структуры, новый UUID и момент создания копии                                                                                      |
| `crossing`                         | Ссылка на прежний ключ ПУ-66; `snapshot: null` означает, что карточка ещё не сверена                                                      |
| `template`                         | Код `b33` или `b34`, ссылка на источник из прототипа и `reviewStatus: not-verified`                                                       |
| `parameters`                       | Направления, расстояния до знаков в метрах, скорости в км/ч, зона работ в метрах и отдельные подписи; сохранены параметры обоих вариантов |
| `titleBlock`                       | Реквизиты шапки исходного проекта                                                                                                         |
| `placements`                       | Стойки и элементы с прежними ID, порядком, привязкой и SVG-координатами; признак автоматического построения сохранён                      |
| `nextPlacementId`                  | Номер следующего объекта; при повреждённом счётчике выбирается свободный номер и показывается предупреждение                              |
| `source.originalJson`              | Точный текст исходного `v: 1`, включая поля, которых ещё нет в модели v2                                                                  |

## Правила чтения

- Принимаются только `v: 1` автономного редактора и `schemaVersion: 2`. Неизвестная версия получает явную ошибку.
- Поля с неправильными типами, повторяющиеся ID, нечисловые расстояния и отсутствующий текст надписи не исправляются молча. Ошибка содержит путь поля, например `params.d150`.
- Пустое значение расстояния становится `null` с предупреждением. Реальные метры отделены от условных SVG-координат; текстовые подписи зоны работ не пересчитываются автоматически.
- Исходный файл не перезаписывается. Новый JSON содержит исходный текст, который можно скачать отдельно. Импорт v2 сохраняет тот же ID и дату, не создавая ещё одну миграцию.
- Импорт не сверяет номер знака, геометрию переезда, применимость Б.33/Б.34, фактические расстояния или порядок согласования. Для этого потребуются актуальные каталоги и предметная проверка.
- Локальный SQLite-реестр ПУ-66 хранится отдельно. Он пока не меняет `crossing.snapshot` импортированной схемы и не заполняется из её JSON автоматически.
- Форма параметров меняет только `parameters` и `titleBlock`; панель объектов меняет `placements` и при добавлении увеличивает `nextPlacementId`. Перед применением проверяются числа и общая схема v2. Ручная правка или перемещение объекта снимает его признак `generatedByTemplate`, сохраняя ID и привязку; удаление не переиспользует ID. `id`, `createdAt`, `source.originalJson`, код шаблона и ссылка на карточку сохраняются. Изменение расстояний и подписей не перестраивает объекты листа. Отмена и повтор доступны лишь для применённых изменений текущей сессии, до 30 шагов.
- При явном локальном сохранении вся схема v2, включая `source.originalJson`, записывается в SQLite с отдельным номером редакции и временем сохранения. Повторный снимок без изменений не создаёт редакцию; запись по устаревшему номеру отклоняется. Восстановление прежнего снимка создаёт новую редакцию, сохраняя его `id` и `createdAt`. Формат JSON v2 от этого не меняется; история действий интерфейса в SQLite не хранится. Сохранённые редакции входят в резервную копию базы.

Пример проекта для тестов находится в `src/domain/__tests__/import.test.ts`. Он использует условный переезд `TEST-001` и вымышленные реквизиты; реальные карточки ПУ-66 и графические материалы в репозиторий не включены.

Для ручной сверки доступны файлы `tests/fixtures/manual-v1.json` (Б.33) и `tests/fixtures/legacy-b34-manual.json` (Б.34). Экран показывает значения параметров, реквизиты, порядок объектов и условные координаты. Рабочая область разрешает X как привязку плюс смещение; Y у элемента остаётся абсолютной координатой, у стойки — смещением от условного ряда соответствующей стороны. Масштаб просмотра не изменяет JSON. Область не строит полный лист и не определяет применимость шаблона. Точные исходные тексты обоих файлов сохраняются при переносе в `source.originalJson`.
