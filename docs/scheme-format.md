# Формат проекта версии 5

Текущий экспорт содержит `schemaVersion: 5`. Файлы v1–v4 читаются с преобразованием в памяти; исходные снимки SQLite не переписываются. Новое сохранение создаёт редакцию v5. Старые поля из v1 сохраняются точно в `source.originalJson`, но этот текст конфиденциален и повторяется в каждой редакции SQLite.

| Поле                                                                                                                   | Содержание                                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `crossing`                                                                                                             | Идентификатор и источник данных; локальная ПУ-66 закрепляется только явным действием, с ограниченным снимком и редакцией.                                                                          |
| `template`                                                                                                             | Б.33/Б.34, ссылка на ОДМ, статус `not-verified` и версия условной геометрии `draft-1`.                                                                                                             |
| `parameters.workZones`                                                                                                 | Измеренные размеры активной зоны; для вновь созданного проекта второй вариант может быть `null`.                                                                                                   |
| `parameters.signDistancesMetres`                                                                                       | `d300`, `d250`, `d150`, `d50`, `n100`, `n50`; неизвестное значение — `null`.                                                                                                                       |
| `parameters.location`, `signSize`, `settlementSpeedKmh`, `lastSettlement`, `frontStyle`, `frontFromPu66`, `regulation` | Решения и исходные условия составителя. `regulation` содержит `mode`, `hourly`, `k`, `vis`, `straight`, `last`. Импорт v1 сохраняет их, у прежних версий выставляются явные значения по умолчанию. |
| `placements`                                                                                                           | Условные координаты стоек и объектов. Элемент может иметь `position.zoneFraction`, добавляемую как доля `(Z1 − Z0)` к `x`; перемещение вручную снимает признак `generatedByTemplate`.              |
| `titleBlock`                                                                                                           | Реквизиты листа; утверждает владелец дороги, согласовывает Госавтоинспекция.                                                                                                                       |
| `source`                                                                                                               | `created-in-editor` либо `legacy-html-v1` с точным исходным JSON.                                                                                                                                  |

## Импорт и построение

- Импорт принимает v1 до 10 МБ и v2–v5 до 32 МБ, проверяет известные поля, уникальность ID и числовые значения. Неизвестные поля v1 сохраняются только в исходном JSON; отчёт прямо называет их пути. v2–v5 используют строгие схемы.
- Фронт менее 30 м выбирает Б.34, от 30 м — Б.33 по подтверждённому правилу проекта. Ровно 30 м требует отдельной предметной сверки из-за расхождения подписи и обозначения ОДМ.
- При сборке условного шаблона составитель выбирает местоположение и режим Б.34. Вариант со знаками 2.6/2.7 требует введённой интенсивности менее 250 авт./ч, достаточной видимости и отвода 15 м; один регулировщик требует отметки о прямом участке и видимости. Эти проверки основаны на ОДМ 218.6.019-2016, п. 4.1.8.3, 5.4.4, 8.1.3.1, 12.7.2–12.7.3 и рис. Б.33/Б.34. Координаты размещения — эскизные, а не физические расстояния и не подтверждение применимости знаков.
- Пересборка удаляет только объекты с `generatedByTemplate: true`. Ручные объекты и уже изменённые объекты шаблона остаются; изменение параметров само по себе не перестраивает расстановку.
- Панель проверки и печать работают с применённым снимком. Маркеры расстояний подставляются только для введённых значений. Лист показывает коды знаков и выбранные поля ПУ-66 (`location`, `axisLabel`, `roadName`, `crossingWidthMetres`). Исходная книга, техническая таблица и исходный v1 JSON на лист не выводятся. Это черновик для внутренней сверки.
- Текущий проект хранит коды PNG без закрепления конкретной редакции изображения. Обновление архива может поменять вид прежнего листа; выпускной режим и закрепление редакции остаются задачами перед релиз-кандидатом.

Ежегодная сверка ПУ-66 линейным подразделением ведётся в отдельном журнале локальной SQLite. Контрольная дата — 30 января, новая редакция карточки не наследует статус. Журнал не включён в JSON и лист.
