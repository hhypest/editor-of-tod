# А5: развитие архитектуры перед 0.4.0 и 0.5.0

Тип: план / согласованная техническая очередь; реализация проверяется по задачам.

Согласовано 30.10.2026 после архитектурного аудита main a5ad72f и повторной сверки с main 8062f0b. [ROADMAP](../../ROADMAP.md) задаёт оперативный порядок; GitHub issues содержат критерии и фактический статус. Принятые А4/#135, #191, #184, #137 и #138 остаются завершёнными. Новый риск не отменяет выполненный результат.

## Область и основания

Подтверждены концентрация обязанностей в модели/миграциях, широкий фасад сессии, распределённые переходы состояния, workflows в App и крупных формах, недостаток межмодульных запретов. Это очередь сопровождаемости P1/P2, без установленного аварийного отказа или основания переписывать приложение.

Часть исходных замечаний требует ограничений: дочерние views уже получают узкие Pick-команды; recovery copy ID и owner окна различаются намеренно; coverage уже собирается в Linux CI, но порогов нет. Анализатор проверяет объявленный граф, а не всю семантику. Существующие maps/catalog/archive после #243–#246 повторно не переделываются.

## Участки повышенного внимания

Ответственность указана ролью для ревью, без назначения конкретного исполнителя. Размер файла — повод оценить причины изменения, а не автоматический дефект.

| Область и текущие участки                                   | Ответственный за контракт                                 | Связанная задача |
| ----------------------------------------------------------- | --------------------------------------------------------- | ---------------- |
| Модель, import и миграции: model/import                     | Сопровождающий совместимости проектов                     | #256             |
| Нормативные definitions/подтверждения: normative-parameters | Сопровождающий нормативной модели и предметный специалист | #257             |
| Review, marks и готовность выпуска                          | Сопровождающий проверки схемы                             | #251             |
| Sheet drawing, draft sheet и геометрия                      | Сопровождающий листа                                      | #258             |
| App, ProjectSession, stores и recovery                      | Сопровождающий состояния редактора                        | #249, #250, #252 |
| SchemeDetailsEditor/NewScheme                               | Сопровождающий форм схемы                                 | #253             |
| ImportedData/NormativeDocuments                             | Сопровождающий реестров и источников                      | #254             |

Изменение такого участка выделяет ответственность либо объясняет, почему перенос сейчас опаснее. Общий запрет всех pure domain calls из UI и пороги «300 строк / 15 полей / 4 модуля» не вводятся.

## Постоянное ведение риска

1. Обнаруженный риск оформляется issue с триггером, доказательством, последствиями, границами и критериями. Категория (architecture, maintainability, test gap, performance, documentation drift) записывается в описании; используется существующий label «технический долг».
2. Сопровождающий соответствующего контракта оценивает влияние и зависимости; ROADMAP ссылается на веху, не копирует все критерии и текущие отметки выполнения.
3. PR содержит [бюджет изменения](../../CONTRIBUTING.md#архитектурное-влияние-pr). Исключение/отсрочка адресные, с причиной и задачей продолжения; ослабление проверки не доказывает устранение риска.
4. Задача закрывается после включения результата и подтверждения её критериев на точном SHA. Документальный PR не завершает технические переносы. Перенос риска в другую веху требует явного решения.
5. Принятие вехи означает выполнение её ограниченного объёма. Отсутствие всех будущих архитектурных рисков не утверждается.

## Сохранность и последующие работы

Чистый перенос сохраняет JSON v11 / SQLite v13, читатели прежних v1/v2–v10, исходные snapshots, evidence/marks, расстояния, undo/redo, revision guards и recovery. Изменение поведения — отдельный результат с основанием и проверкой. Необъяснённые расхождения не скрываются обновлением golden.

Крупные переносы форм ждут принятого результата #242; текущая приёмка 0.3.0 не подменяется А5. [Ресурсы и реструктуризация справки 0.9.0](0.9.0-resources-and-help.md) начинаются только после завершения и приёмки 0.5.0: это следующий этап, а не часть А5.
