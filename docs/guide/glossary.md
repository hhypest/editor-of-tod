# Словарь интерфейса и документации

Тип: действующая справка для составителя и разработчика. Сверено 30.10.2026 по интерфейсу и встроенной справке main a5ad72f. При изменении подписи в программе обновляют руководство и справку вместе.

| Термин                      | Что означает                                                                                                                                                                                          |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Лист A4                     | Печатный лист альбомной ориентации. Не путать с архитектурным этапом А4 — завершённым серверным рефакторингом                                                                                         |
| Фронт работ                 | Длина ремонтируемой части. Отгон и буфер в неё не входят                                                                                                                                              |
| Отгон / прежнее «отвод»     | Длина переходного участка. В текущей форме и некоторых прежних документах встречается «отвод»; это название поля, не дополнительная длина сверх отгона. В нормативных пояснениях используется «отгон» |
| Применить правки            | Перенести введённые значения формы в текущий документ. До применения лист/review используют прежний снимок                                                                                            |
| Сохранить проект            | Записать редакцию в локальную базу. Это действие отличается от применения формы и скачивания JSON                                                                                                     |
| Скачать файл проекта        | Получить переносимый JSON текущего проекта. Отмена скачивания не подтверждает запись в базу                                                                                                           |
| Копия восстановления        | Записанные текущие правки и неприменённый ввод для возврата после закрытия/сбоя. Она не заменяет backup всей базы                                                                                     |
| Редакция проекта            | Неизменяемая сохранённая версия. Возврат к ней создаёт новую текущую редакцию                                                                                                                         |
| Снимок ПУ-66                | Разрешённые сведения выбранной редакции карточки, закреплённые в проекте. Это не вся книга и не автоматически обновляемая ссылка                                                                      |
| Подтверждение параметра     | Явная запись проверенного значения по источнику в локальном реестре                                                                                                                                   |
| Основания решения           | Историческая запись условий, значений и источников скорости/регулирования в проекте; не заменяет ручную предметную проверку                                                                           |
| Черновой / выпускной лист   | Режим вывода. Выпуск требует устранить блокировки и выполнить проверку; новая правка возвращает черновик                                                                                              |
| Принято / в main / выпущено | Разные состояния: решение специалиста о точной сборке, включение изменения в основную ветку и опубликованная поставка                                                                                 |

Рабочий маршрут — [начало работы](getting-started.md). Текущая приёмка — [0.3.0](../verification/0.3.0/README.md); технические детали — на втором уровне [каталога](../catalog.md).
