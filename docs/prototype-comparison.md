# Сравнение с автономным прототипом

Материал фиксирует происхождение требований по предоставленному HTML и руководству. Указанные возможности исходника не становятся автоматически готовыми функциями Vue. Текущие задачи и критерии — в [дорожной карте](../ROADMAP.md), совместимость — в [документе о переносе](migration.md).

## Что изменилось в автономном редакторе

| Загрузка нескольких ПУ-66 XLSX в браузере, станционные карточки, заполнение схемы из карточки       | Импорт до 100 файлов с просмотром, станционные карточки, создание проекта из найденной карточки (П1). Интенсивность, категория дороги, видимость и графа «Норма» показываются на этапе «Схема движения» из локальной базы и подставляются кнопкой; в снимок проекта не входят. Расстояния и скорости подставляются из нормативных параметров и остаются редактируемыми (формат v7); подсказка «в населённом пункте» по названию дороги — шаг П4. |

Лист A4 в SVG, выпускной режим, PDF через печать браузера и PNG около 300 dpi (П8). Переносной `editor-of-tod.exe` собирается командой `npm run build:exe`; испытание на рабочем месте выполнено составителем 30.09.2026.                                                                                                                      |

Встроенные в автономный файл записи переездов и изображения знаков не переносятся в публичный код. Работа с ними остаётся через локальные реестры, явное закрепление редакций и правила доступа к данным.

### Числа и условия из автономного HTML

Следующие значения описывают алгоритм прототипа, **но не являются утверждёнными требованиями к Vue**. До реализации каждого правила нужно проверить действующую редакцию источника, точное условие применимости и получить предметное подтверждение; порядок проверки задан в [реестре источников](standards.md).

| В исходном HTML                                         | Источник, на который ссылается код, и что осталось проверить                                                                                                                                                                                                                                                            |
| ------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Умолчания 100 и 50 м для двух стоек в населённом пункте | ГОСТ Р 52289-2019, п. 5.2.2 базовой редакции задаёт диапазон **50–100 м** для предупреждающих знаков, а не обязательную пару 100/50 м. Состав стоек, повторный 1.25, ступени скорости и применимость изменений № 1 и № 2 проверить отдельно по пп. 5.2.27, 5.4.22 и действующей редакции.                               |
| Знаки 2.6/2.7 при интенсивности менее 250 авт./ч        | HTML ссылается на ОДМ 218.6.019-2016, п. 5.4.4 и рис. Б.34; нужно сверить одновременно длину участка, видимость, интенсивность в двух направлениях и пограничное значение. Суточную величину из ПУ-66 нельзя напрямую считать часовой.                                                                                  |
| Переключение на двух регулировщиков свыше 500 авт./ч    | Это решение функции `regInfo()` в HTML. Код ссылается на ОДМ 218.6.019-2016, п. 5.4.2 как на границу поочерёдного пропуска, но **не подтверждает**, что превышение само по себе требует именно двух регулировщиков. Проверить допустимость такого пропуска и другие способы организации движения до переноса алгоритма. |
