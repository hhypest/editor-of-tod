# Регрессия совместимости и сохранности

Тип: действующий ручной чек-лист. Сверено 30.10.2026 по main a5ad72f; выполнение на новой сборке не заявляется. Используйте отдельную тестовую папку, вымышленные файлы и резервную копию. [Методика](../../engineering/testing.md) · [Устройство recovery](../../engineering/state-and-recovery.md) · [Текущая #108](../0.3.0/README.md).

## Форматы и сохранённые редакции

Текущий экспорт — `schemaVersion: 11`; поддерживаемые прежние файлы — `v: 1` и `schemaVersion: 2–11`. SQLite обновляется до версии 13: поддерживаемая старая файловая база получает копию до изменения, текущая база не получает повторную миграцию. Особая историческая v2 и очистка прежних SVG проверяются техническими тестами, а не на рабочей базе; см. [совместимость](../../engineering/compatibility.md).

| ID   | Действие                                                                                                     | Ожидаемый результат                                                                                                                                                                                                   |
| ---- | ------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CR01 | Открыть [manual-v1.json](../../../tests/fixtures/manual-v1.json), скачать файл проекта, открыть его повторно | Идентификатор, createdAt, параметры, объекты, исходный legacy JSON сохранены; экспорт v11. Имя `scheme_TEST-001_v11.json` может получить суффикс браузера при повторном скачивании. Исходный файл не перезаписывается |
| CR02 | Открыть прежние разрешённые форматы, неизвестную будущую версию, повреждённый и слишком большой файл         | Поддерживаемый файл преобразуется в памяти. Ошибочный отклоняется с объяснением без потери открытого документа/ввода. Внутренний SHA SQLite не делает внешний JSON неполным                                           |
| CR03 | Сохранить проект, применить и сохранить изменение, повторить сохранение без изменения                        | Появляются редакции с историей; повтор без изменений не создаёт лишнюю. Скачать прежнюю редакцию можно без изменения текущей                                                                                          |
| CR04 | «Вернуться к этой версии» у прежней редакции                                                                 | Создаётся новая текущая редакция; промежуточные остаются. Исторический снимок читается без переписывания базы                                                                                                         |
| CR05 | Открыть одну редакцию в двух окнах, сохранить разные правки                                                  | Устаревшее сохранение получает конфликт; открытые правки остаются, база не перезаписывается молча                                                                                                                     |

## Восстановление, два окна и отказ связи

| ID   | Действие                                                                                                | Ожидаемый результат                                                                                                                                                                          |
| ---- | ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CR06 | Изменить применённые данные и оставить неприменённый ввод, дождаться записи recovery, закрыть и открыть | В «Копиях восстановления» доступны записанный документ и ввод. Последние изменения до завершения записи не объявляются гарантированно сохранёнными                                           |
| CR07 | Оставить первое окно работающим и открыть второе                                                        | Чужую активную копию нельзя восстановить/удалить. После обычного закрытия владение освобождается; после аварии учитывается аренда. Истечение аренды требует явного захвата копии             |
| CR08 | Приостановить окно, восстановить копию в другом, затем вернуться в первое                               | Прежний владелец получает конфликт и сохраняет свои открытые правки; поздняя запись не перетирает нового владельца                                                                           |
| CR09 | Во время записи внести новые правки, сменить проект или закрыть форму                                   | Поздний ответ не помечает другой документ сохранённым; новый ввод остаётся pending до своей записи. Сессия/очередь не дублируются                                                            |
| CR10 | Остановить API или сеть во время сохранения/recovery, затем вернуть связь                               | Нет ложного сообщения об успехе. Правки и ввод остаются, ошибка/неопределённая доставка объяснены, повтор не создаёт чужую редакцию. Запись recovery возобновляется по действующему сценарию |
| CR11 | Начать скачивание JSON и отменить его                                                                   | Отмена скачивания не подтверждает локальное сохранение и не удаляет recovery. Экспорт исходного JSON отдаёт прежний текст                                                                    |
| CR12 | Проверить настоящий сон Windows и пробуждение                                                           | Фиксируются длительность/среда и фактический результат; правки остаются, статус владения перечитывается. Подмена времени в unit-тесте не засчитывается вместо сна                            |

## Backup, обновление и возврат

| ID   | Действие                                                                                        | Ожидаемый результат                                                                                                                                                 |
| ---- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CR13 | Создать копию через приложение, остановить программу и открыть копию в отдельной тестовой папке | Проекты, редакции, источники, изображения и документы читаются. Оригинал сохранён отдельно; восстановление не выполняется поверх работающей базы                    |
| CR14 | Запустить обновление тестовой старой базы; отдельно воспроизвести отказ записи backup           | С поддерживаемой старой базой копия предшествует изменению. При отказе обязательной копии обновление не начинается; повтор текущей версии не создаёт новую миграцию |
| CR15 | Запустить exe дважды для той же базы и отдельно для другой базы                                 | Повтор той же базы открывает работающую программу; другой экземпляр/база различаются. Не возникает скрытой второй записи в ту же рабочую базу                       |

Атомарность SQL, source cleanup, порядок ошибок и rollback проверяют [защитные серверные тесты](../../engineering/server-and-storage.md#миграции-и-проверки). Ручной чек-лист не требует создавать сбой SQL на рабочих данных. Первоначальная #108 принята на a5ad72f; затронутую совместимость после будущей П6 проверяют заново.
