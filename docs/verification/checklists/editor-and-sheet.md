# Регрессия редактора и листа

Тип: действующий ручной чек-лист; выполнение на новой сборке не заявляется. Сверено 30.10.2026 по main a5ad72f и встроенной справке. Проверяющий фиксирует точный срез по [методике](../../engineering/testing.md). Используйте вымышленные данные и отдельную базу. Сценарии исправления фронта из открытого PR #242 проверяются [отдельно](../0.3.0/README.md#проверяемый-блок-103).

## Проект и применённый ввод

Для числовых примеров выберите учебную карточку с длиной п. 8 не меньше 31 м, укажите допустимые условия работ и подтвердите используемые нормативные параметры. Пороговые ожидания ниже относятся к порогу 30 м; при ином согласованном значении запишите его и пересчитайте границы сценария.

| ID   | Действие                                                                                | Ожидаемый результат                                                                                                                                                                                                                                     |
| ---- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ED01 | На пустой базе открыть «Проекты» → «Новый проект»                                       | Без карточек ПУ-66 создать проект нельзя; импорт и открытие прежнего файла доступны. Ошибка реестра объясняется, открытый проект не теряется                                                                                                            |
| ED02 | Импортировать учебные карточки, найти/выбрать одну, затем выбрать другую                | Поиск различает км/пк и учитывает участок/станцию; видно, что будет закреплено. Создание до выбора карточки и обязательных условий недоступно. Изменение карточки после выбора требует повторной сверки                                                 |
| ED03 | Создать проект и пройти четыре этапа                                                    | «Исходные данные» → «Схема движения» → «Знаки и объекты» → «Проверка и лист». До первой сборки типовые объекты сами не появляются                                                                                                                       |
| ED04 | Ввести правки, перейти на другой этап, применить и отменить ввод                        | Переход сохраняет ввод открытой формы; review/лист используют применённые данные. Некорректное число объясняется рядом с полем. «Отменить ввод» возвращает применённые значения                                                                         |
| ED05 | Проверить фронт 29,9 / 30 / 30,1 при исходном пороге проекта 30 м                       | Выбор по правилу проекта: Б.34 / Б.34 / Б.33. Действующий порог и основание видны в форме. Открытие старого файла с иным вариантом не исправляет его молча; расхождение требует явного решения                                                          |
| ED06 | Собрать шаблон, добавить ручную надпись, изменить значимый параметр этапа 2 и применить | Типовые объекты перестраиваются; ручные и изменённые вручную типовые сохраняются. Сообщение называет оставшиеся ручные правки. Одна отмена возвращает параметры и объекты; при отказе параметры применены, прежние объекты сохранены и причина показана |

## Объекты, расстояния и история

| ID   | Действие                                                                                | Ожидаемый результат                                                                                                                                                           |
| ---- | --------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ED07 | Добавить/скопировать/удалить объект, выполнить отмену и повтор                          | Объекты и выбранный ID согласованы, undo/redo восстанавливают целое действие. Ручной перенос типового объекта снимает его автоматическое владение                             |
| ED08 | Задать стойке подход и distance, перенести мышью/стрелками                              | Положение на листе и подпись следуют из метров; отображается будущее расстояние. Координаты эскиза не выдаются за измерение местности                                         |
| ED09 | Внести значения вне подтверждённых нормативных диапазонов и перейти из замечания к полю | Находка показывает изменённое значение и источник; «Перейти» открывает нужный этап/поле. Возврат нормативного значения явный; ручное число не заменяется молча                |
| ED10 | Проверить ступени 3.24, интервалы и несколько табличек на стойке                        | Ступени используют скорость на подходе и параметры, ручные изменения сохраняются. Интервал и число табличек — отдельные пункты ручной сверки, не универсальный запрет выпуска |
| ED11 | Собрать учебный пример с отгоном 10, буфером 10, фронтом 27,4 и затем 27,5 м            | Табличка протяжённости 8.2.1 учитывает весь участок: 47 и 48 м. При изменении подтверждённых параметров исходные значения сценария записываются отдельно                      |

## Проверка, выпуск и изображение

| ID   | Действие                                                                                | Ожидаемый результат                                                                                                                                                                          |
| ---- | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ED12 | Отметить пункт «Проверено», изменить его данные/основание                               | Отметка становится устаревшей при значимом изменении; неподтверждённое или заблокированное основание нельзя удостоверить отметкой. Не связанные правки не снимают её без причины             |
| ED13 | Оставить обязательное условие или связанное расстояние пустым, проверить регулировщиков | Выпуск закрыт с конкретной причиной; переход ведёт к нужному полю/объекту. Количество и положение регулировщиков соответствуют выбранному способу пропуска, это не снимается ручной отметкой |
| ED14 | Заполнить реквизиты, проверить черновик, выполнить предметную сверку и включить выпуск  | Черновые/служебные строки различаются. Любое изменение возвращает черновик; подтверждение выпуска не сохраняется как постоянное разрешение в файле проекта                                   |
| ED15 | «Печать листа A4» / «Печать черновика A4» и «Скачать PNG»                               | Альбомный A4 читаем целиком; надписи, коды, направления, утверждённые поля ПУ-66 и годы видимости различимы. Переполнение объясняется, PNG открывается и соответствует применённому листу    |
| ED16 | Закрепить изображения знаков, обновить каталог, изменить набор кодов проекта            | Исторические PNG остаются у закреплённого проекта. Новый набор кодов снимает закрепление с объяснением; повторное закрепление выполняется явно                                               |
| ED17 | Проверить в населённом пункте, вне него и с существующими знаками, обоими подходами     | Условия, расположение и применимость сверяются отдельно. Условные примеры не объявляются утверждёнными эталонами #109; примыкания #107 не считаются реализованными                           |

Подробные основания — [нормативная модель](../../standards.md), [ПДД](../../pdd.md), [формат проекта](../../scheme-format.md). Печатный формат **A4** и завершённый архитектурный этап **А4** различаются в [словаре](../../guide/glossary.md).

## Регрессия принятых предметных блоков

| ID   | Действие                                                                                                   | Ожидаемый результат                                                                                                                                                                                                                       |
| ---- | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ED18 | Выбрать карточку с признаком улицы/населённого пункта, посмотреть подсказку, затем подтвердить и применить | Показ подсказки сам не меняет место или объекты. Подтверждение, отмена ввода и применение различаются; изменение можно целостно отменить                                                                                                  |
| ED19 | Проверить одиночный знак 1.25 по двум подтверждённым параметрам п. 5.2.27, ниже/на/выше их границ          | Расстояние и предел скорости учитываются отдельно. Неизвестный подход не считается доказательством одиночного знака на другом. Табличка относится к своему знаку; переносная опора и фактическая применимость остаются предметной сверкой |
| ED20 | При подтверждённых параметрах изменить поток/видимость/условия и посмотреть подсказку пропуска Б.34        | Предложение объясняется условиями и применяется явно. При неподтверждённых параметрах нет ложной готовности; изменение значимых условий требует повторной сверки оснований                                                                |
| ED21 | Сменить способ пропуска при своём значении отгона, просмотреть предложение, подставить и отменить ввод     | Предложение не заменяет ручное число молча; подстановка явная, прежнее значение можно вернуть. Undo/redo и сохранение согласованы с применёнными параметрами                                                                              |
| ED22 | Записать основания скорости, затем изменить 3.24/3.25/3.31, подход/метры и отдельно координаты/другой знак | Значимые входы делают запись устаревшей; одно перемещение на листе и правка постороннего знака не снимают запись скорости. Изменение данных/источников требует явной новой записи и проверки                                              |

Исходные принятые результаты П4/П5/предложения отгона — [протокол 24.10](../reports/2026-10-24-subject-blocks.md). Эти строки являются повторяемыми сценариями, а не новым подтверждением их выполнения.
