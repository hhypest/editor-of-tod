# Регрессия реестров и источников

Тип: действующий ручной чек-лист; результат фиксируется для точной сборки. Сверено 30.10.2026 по main a5ad72f. Подготовка — [методика](../../engineering/testing.md); текущий состав полей ПУ-66 и принятая #110 — в [проверке версии](../0.3.0/README.md). Нужны разрешённые локальные материалы; публичные примеры вымышленные.

| ID   | Действие                                                                                                  | Ожидаемый результат                                                                                                                                                                        |
| ---- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| RG01 | Запустить программу с новой тестовой базой и пройти «Настройка программы»                                 | Четыре шага выполняются внутри мастера. Назад сохраняет ввод/файлы открытого мастера; во время записи переход заблокирован с объяснением                                                   |
| RG02 | «Продолжить позже», затем вернуться к настройке                                                           | Уже записанные данные остаются; незавершённый ввод после закрытия мастера не объявляется сохранённым. Готовность не выставляется по одному факту просмотра                                 |
| RG03 | Выбрать учебные XLSX ПУ-66, просмотреть план и подтвердить импорт                                         | До подтверждения нет записи. Added/changed/unchanged объяснены, перед записью создаётся backup. Изменение базы после preview требует нового плана                                          |
| RG04 | Повторить ту же книгу, затем изменённую; проверить станционный ключ и неоднозначный прежний alias         | Неизменённая книга не создаёт новую редакцию. Изменённая сохраняет историю; разные карточки станции не сливаются. Неоднозначный прежний ключ не выбирается наугад                          |
| RG05 | Зарегистрировать сверку текущей карточки; попробовать будущую дату и импорт новой редакции                | Будущая дата отклоняется. История остаётся у редакций; новая карточка не наследует сверку. Журнал не подтверждает карточку разработчиком и не экспортируется на лист                       |
| RG06 | Исключить карточку с просмотром плана, проверить преемника, затем явно вернуть                            | Обычный список скрывает исключённую карточку; история и прежние снимки проектов сохраняются. План проверяется повторно после backup. Обычный импорт сам не возвращает исключённую карточку |
| RG07 | Выбрать учебный PDF, проверить реквизиты и дату введения, подтвердить добавление; повторить тот же PDF    | Preview не записывает документ; дубликат распознаётся. Дата редакции и введения различаются. Основной документ и изменение связываются явно                                                |
| RG08 | Добавить условную будущую/действующую редакцию, проверить active source и закреплённые PNG                | Будущая редакция не подменяет действующую заранее. При смене действующего источника видно устаревание каталога/оснований; прежний снимок проекта не переписывается                         |
| RG09 | Извлечь знаки из учебного PDF либо просмотреть разрешённый ZIP, поправить неоднозначный код и подтвердить | Есть отдельные preview и запись; исходник не отправляется внешнему сервису. Изменение источника после preview требует повторной проверки. Старые изображения доступны истории              |
| RG10 | Подтвердить параметр с цитатой/страницей/ответственным, сменить редакцию или значение                     | Подтверждение только явной кнопкой. История сохраняется; старое подтверждение не удостоверяет новое основание. Неподтверждённое число явно предварительное                                 |
| RG11 | Открыть ПДД без даты введения, затем указать действующие реквизиты                                        | Дата версии сама не делает ПДД действующим источником. Справочник скорости показывает условия; подстановка и запись оснований — разные явные действия                                      |
| RG12 | Попробовать удалить документ со ссылками из знаков/изменений/подтверждений                                | Удаление блокируется с причиной; PDF и текст сохраняются. Отказ операции не объявляется успешным. Атомарность отказа второй записи защищена отдельными серверными тестами                  |
| RG13 | Скачать диагностический отчёт, проверить сбой и повтор чтения/очистки                                     | Ошибка объясняется; очистка не даёт ложного успеха. В выгрузке нет содержимого проекта, названий карточек и абсолютных путей. Рабочую SQLite/backup к issue не прикладывают                |

Сбой backup, потеря связи и поздний ответ проверяются также по [сохранности](compatibility-and-recovery.md). Точная граница транзакций и отказов — [сервер и хранение](../../engineering/server-and-storage.md), состав безопасной выгрузки — [диагностика](../../engineering/diagnostics.md).

## Цитаты и табличные параметры

| ID   | Действие                                                                                    | Ожидаемый результат                                                                                                                                                                                          |
| ---- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| RG14 | В ПДД открыть подтверждение скорости при буксировке и переход к PDF                         | Предпочтён основной п. 10.4, а не одноимённый пункт приложения; значение и страница сверяются по конкретной редакции. Прежняя ошибочная цитата не становится подтверждением нового источника                 |
| RG15 | Добавить/изменить строку табличного параметра, сохранить и повторно подтвердить те же числа | Строка не теряется и не дублируется; ошибочное значение объясняется. Повторное подтверждение имеет собственное основание/историю; прежняя отметка проверки не удостоверяет новое подтверждение автоматически |

Предыдущая проверка цитаты относится к [RC2 0.2.0](../reports/2026-10-24-release-0.2.0.md); фактическое повторное выполнение записывают для новой сборки отдельно.
