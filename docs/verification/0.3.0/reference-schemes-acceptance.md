Тип: план / чек-лист предметной приёмки; эталоны ещё не приняты.

Подготовлено 30.10.2026 по передаче #107/#109. Принятые S03–S05 исправления #103 подтверждают свои три сценария листа, но не весь набор #109. Базовую проверку готовить на исправлении #242 после слияния; R07 — после реализации и приёмки П6. [Текущая очередь](../../../ROADMAP.md).

Отсутствие рабочего образца не заменяется выдуманным «утверждённым» листом. Для разработки разрешён синтетический дубль; принятие эталона — отдельное решение специалиста по фактическому результату.

## Паспорт проверки

| Поле                                         | Заполнить                          |
| -------------------------------------------- | ---------------------------------- |
| Дата / проверяющий / ОС / браузер / экран    | Локально, публичный итог обезличен |
| Версия / полный Git SHA (40 символов)        | Не заполнено                       |
| Windows exe: номер / ссылка на Actions       | Не заполнено                       |
| SHA-256 exe (64 символа)                     | Не заполнено                       |
| Ссылка/локальный ID разрешённого образца     | Не заполнено                       |
| Подтверждённые параметры/источники/редакции  | Не заполнено                       |
| Режим печати / версия синтетического fixture | Не заполнено                       |

Commit, SHA-256 exe и digest архива Actions — разные поля. Для каждой строки используются статусы «совпадает», «отличается — что именно», «неприменимо — почему», «не проверено». Пустая строка не является положительным результатом.

## Закрепление принятого эталона

1. Записать фактический SHA/сборку, исходные условия, восемь сравнений и явное решение.
2. Подготовить полностью вымышленный эквивалент принятого случая; рабочие листы/PDF/карточки не публиковать.
3. Зафиксировать состав/порядок/расстояния предметными тестами; рисунок — воспроизводимым SVG/PNG golden с известным окружением, без выдачи пикселей за норматив.
4. Связать тест с принятым R и основанием допустимых различий. Обновление golden не скрывает несоответствие.
5. Повторить автоматическую и затронутую ручную проверку при изменении геометрии/формата; R07 добавить после П6.
