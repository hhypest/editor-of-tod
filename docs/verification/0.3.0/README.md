## Проверяемый блок #103

[Контракт и приёмка](front-fix.md) фиксируют 28 принятых пунктов, Git SHA, запуск exe, контрольную сумму и исправление перепутанных полей паспорта. Успешный CI и предметное решение записаны отдельно. Первоначальное «возвращаю на доработку» 29.10 сохраняется в датированном протоколе; его заменяет новый итог 30.10 для указанной сборки.

После совмещения #242 с документальным main сохраняется исполняемый код принятого 50ab628; результат CI совмещения относится к своему SHA. Новая ручная приёмка другого exe не заявляется.

## Примыкания и эталоны

[Контракт П6](../../plans/notes-and-junctions.md) отделяет согласованные сценарии J1–J4/РП1–РП7 от открытых геометрических решений Д2–Д5/Д9 и исходных данных. Приёмка готовой П6 J01–J04 проводится только после отдельной реализации. Отсутствие П6 в принятой сборке фронта не является дефектом #103.

В #109 предложены R01–R06/R08 для базовой проверки и R07 после П6. S03–S05 принятого #103 не закрывают этот набор. [Примеры состава листа](../../reference-schemes.md) не объявляются принятыми эталонами. Реальные JSON/PDF остаются локально; публичные проверки строятся на синтетических дублях.
