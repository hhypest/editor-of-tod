## ПУ-66: повторная регрессия после затронутых изменений

## Совместимость прежнего редактора

Проверить вымышленные/разрешённые локальные примеры четырёх типов: Б.33, Б.34, населённый пункт и станционный переезд. Для каждого открыть исходный JSON, сравнить параметры/геометрию/вложенные данные, сохранить/скачать и открыть повторно. Карточка из файла не должна автоматически добавляться в локальный реестр. Полный исходный JSON сохраняется; преобразование в текущий формат не перезаписывает исходный файл.

После будущей П6 повторяются затронутые импорт и геометрия примыканий. Первоначальная #108 этого нового результата не закрывает. Общая сохранность, конфликты и recovery — в [чек-листе](../checklists/compatibility-and-recovery.md).
