## Что разрешено в отчёте

Журнал содержит известные действия, обобщённые маршруты, тип ошибки и безопасные места в коде. Свободный текст исключения, абсолютные пути, имя функции и неизвестные stack frames не передаются. Сохраняется максимум четыре допустимых кадра со строкой/столбцом. Прежние записи очищаются при чтении; клиентская форма выгрузки не добавляет тексты проекта или ключ переезда.

Отчёт v2 содержит техническое окружение и количества записей. Путь к базе, названия документов, тексты карточек и содержимое проектов в сводку не входят. Ошибка отдельного запроса даёт безопасное null/«недоступно», без исходной ошибки/пути. Наличие обезличенной выгрузки не разрешает прикладывать SQLite, backups или рабочие карточки к issue.

GET diagnostics исключён из общей finish-статистики запросов; POST clear записывается после очистки. Правила rotation/slow request и схема событий принадлежат коду, а не копии чисел в руководстве.

## Перечень допустимых мест кода

[diagnostic-files.generated.ts](../../src/shared/diagnostic-files.generated.ts) создаётся по отслеживаемым рабочим модулям src/server/scripts до разрешения модулей в Vite dev/build/test и при упаковке exe. Runtime не обходит каталоги пользователя. Тесты, декларации, скрытые каталоги, node_modules, неисполняемые файлы и symlinks исключены. `server.cjs` сохраняется для SEA, исторический `server/store.ts` — только для прежних записанных событий.

После переноса исполняемых исходников обновите перечень командой `node scripts/diagnostic-files.ts`; `npm run check:diagnostics` отклоняет рассинхронизацию. Перенос Markdown-документов не меняет этот перечень. Формат hashed browser index и отчёт v2 сохраняются.
