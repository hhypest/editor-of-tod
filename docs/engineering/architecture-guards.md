## Проверяемая матрица

[scripts/architecture-policy.ts](../../scripts/architecture-policy.ts) задаёт именованные, в том числе пересекающиеся, селекторы слоёв. [check-architecture.ts](../../scripts/check-architecture.ts) применяет их при `npm run check:architecture`, входящем в общий check.

| Откуда                           | Запрещённая зависимость                                                 |
| -------------------------------- | ----------------------------------------------------------------------- |
| Клиент src/                      | server/                                                                 |
| Domain/application               | Components, composables, services, presentation, stores и внешний Pinia |
| Domain                           | Application                                                             |
| Исторические formats/frozen      | Текущий domain вне frozen                                               |
| Review-модули                    | sheet-drawing                                                           |
| Любой разрешённый локальный граф | Цикл, включая type-only и статический dynamic import                    |

ESLint отдельно ограничивает Vue, Node-импорты и browser globals в core; корневая сессия не должна возвращать прямые DOM/fetch/таймеры вместо адаптеров. Новую ответственность и новое направление зависимости нужно сначала объяснить, затем согласованно изменить реализацию, политику и её негативные примеры. Отключение проверки не является способом завершить перенос.

## Что видит анализатор

Рабочие TS/TSX/MTS/Vue/MJS-модули src/server разбираются без тестов и деклараций. Vue SFC читает официальный `@vue/compiler-sfc.parse`: script и script setup, ошибки структуры, поддерживаемый язык и внешнее script src. HTML-комментарии не становятся кодом; регулярное выражение не используется вместо SFC-парсера.

TypeScript AST учитывает import, type import, re-export, import type expressions и строковый `import()`. Разрешаются относительные пути и alias `@/`, точные расширения и index; query/hash снимаются перед поиском. Raw-импорт кода остаётся ребром, текстовые активы вроде LICENSE не являются узлами. Неизвестный локальный модуль останавливает проверку.

Строковый литерал и шаблонная строка без подстановок разрешаются статически. Вычисляемый import, конкатенация и шаблон с подстановкой отклоняются как непроверяемые; обходной allowlist для них не вводится. Анализатор проверяет статический граф и объявленные запреты; качество ответственности модулей, runtime/code generation и предметная корректность требуют отдельного рассмотрения.

## Когда перенос считается сохранным

Одна сессия, история и recovery-очередь на окно; одно SQLite-соединение для общей атомарной операции; неизменные форматы, рисунок и отпечатки при чистом переносе. Новая функция или нормативное изменение оформляется отдельно с проверяемым основанием. Необъяснённое изменение контракта исправляют в реализации, а не обновлением golden или ослаблением теста.
